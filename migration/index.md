# Migration Project

## Overview

This project examines migration as a socio-economic phenomenon driven by macroeconomic conditions, with a particular focus on inflation and unemployment as key push factors. The study investigates how changes in these variables over time influence individuals’ decisions to migrate, particularly among skilled workers such as nurses who seek improved economic opportunities.

Using secondary data, the project applies data analysis techniques to explore trends in inflation and unemployment in Nigeria. The data is cleaned, transformed, and analysed to identify patterns and relationships between economic instability and outward migration pressures.

The analysis is guided by the premise that worsening economic conditions, such as rising inflation and high unemployment, reduce purchasing power and limit access to employment opportunities, thereby increasing the incentive to migrate. By examining these trends over time, the project aims to provide insight into how macroeconomic environments contribute to migration dynamics and skilled labour outflows.
